AgriJarvis

AgriJarvis is a full-stack smart farming platform designed to assist Indian farmers in making data-driven agricultural decisions through an integrated digital ecosystem. The system combines artificial intelligence, real-time data processing, and intuitive user interfaces to address key challenges in modern farming. The platform features an AI-powered chatbot that supports both text and voice-based interaction with multilingual capabilities (Hindi and English), enabling accessibility for farmers across diverse regions. It provides intelligent crop recommendations based on user inputs such as soil conditions, location, and environmental factors, helping optimize yield and resource utilization. AgriJarvis integrates real-time weather forecasting using location-based services, allowing farmers to plan irrigation, harvesting, and other critical activities effectively. Additionally, the system includes an image-based crop health analysis module, where users can upload photos of crops to detect pests and diseases and receive actionable solutions. The platform also delivers updates on government agricultural policies, subsidy schemes, and crop insurance programs, ensuring farmers stay informed about financial and regulatory support. A dedicated farm management dashboard allows users to track activities, monitor farm data, and manage operations efficiently. From a technical perspective, the system is built using a modern full-stack architecture with React for the frontend, Node.js for backend services, and PostgreSQL for database management. The application emphasizes scalability, responsive design, offline accessibility considerations, and secure data handling. AgriJarvis aims to bridge the gap between traditional farming practices and modern technology by providing a unified, intelligent assistant tailored specifically for the Indian agricultural ecosystem..

Versioned Document Tracker – Web-Based Document Management System

Versioned Document Tracker is a web-based application designed to manage and track multiple versions of documents efficiently. The system allows users to create, update, and maintain different versions of documents while preserving change history for better traceability. The application enables structured document handling where each update is stored as a new version, ensuring that previous data is not lost. Built using HTML, CSS, and JavaScript, the project focuses on a clean and responsive user interface with smooth interactions.
